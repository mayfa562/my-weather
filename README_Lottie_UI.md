# My weather — Lottie weather icon update

This update uses the supplied Meteocons Lottie fill animations. The hero weather illustration is enlarged and intentionally overlaps the lower-right of the temperature. All WeatherIcon instances receive a soft shadow/halo for contrast.

Condition mapping:
- 01 clear sky -> clear day/night
- 02 few clouds -> partly cloudy day/night
- 03 scattered clouds -> cloudy
- 04 broken/overcast clouds -> overcast day/night
- 09 shower rain -> rain
- 10 rain -> rain
- 11 thunderstorm -> thunderstorms day/night
- 13 snow -> snow
- 50 mist/fog/atmosphere -> fog day/night
